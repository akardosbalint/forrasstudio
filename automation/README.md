# Automation

Ez a mappa a jövőbeli Python-alapú automatizálásoknak és AI-scripteknek van
fenntartva (pl. lead-scoring a beérkező visszahívás-kérésekhez, riportgenerálás,
egyéb AI-alapú funkciók). Nem tartozik a landing page futásidejű
(Next.js/Node.js) kódjához — a jelenlegi landing page-nek nincs szüksége
Python-komponensre, ez a mappa egyelőre csak helyfoglalás.
